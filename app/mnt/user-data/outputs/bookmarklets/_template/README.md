## 🚀 Installazione

1. Crea un nuovo segnalibro nel tuo browser
2. Incolla il seguente codice come URL:

```javascript
javascript:(function(){
    var s = document.createElement('script');
    s.src = 'https://pbielli.github.io/bookmarklet/app/bookmarklets/FOLDER_NAME/main.js?v=' + new Date().getTime();
    document.head.appendChild(s);
})();
```

3. Clicca sul bookmarklet quando sei sulla pagina desiderata

## 💡 Utilizzo

1. Apri la pagina web su cui vuoi usare il bookmarklet
2. Clicca sul segnalibro creato
